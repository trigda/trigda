⚙️ Setup Guide

Google Sheets + Gmail Integration

Yeh guide follow karo — 10 minute mein sab kuch live ho jaayega. Form submit hote hi Google Sheets mein data save hoga aur Gmail par notification aayega!

✅ Kya milega: Demo bookings, Contact messages, aur Leads automatically Google Sheets mein save honge + Gmail notification milega — bilkul FREE, koi server nahi chahiye!

1

Google Sheets Banao

Pehle ek nayi Google Sheet banao jahan sab data save hoga:

📊 sheets.google.com par jao

→ "Blank" par click karo → Sheet ka naam rakh do: "TRIGDA Data"

→ URL se Sheet ID copy karo — yeh hoga:

https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms/edit ↑ YEH HAI SHEET ID

⚠️ Sheet ID save kar lo — Step 3 mein kaam aayega

2

Google Apps Script Kholo

Google Sheet mein Extensions → Apps Script click karo:

📸 [Extensions menu → Apps Script option]

Ya seedha yahan jao:

🔗 script.google.com

→ "New Project" click karo → Project naam rakh do: "TRIGDA Forms"

3

Script Paste Karo

Editor mein jo code pehle se hai (function myFunction...) woh delete karo aur google-apps-script.js file ka sara code paste karo.

Phir 2 cheezein change karo:

// Line 8 — Apni Gmail daalo: const ADMIN_EMAIL = "apki_email@gmail.com"; // ← YAHAN APNI EMAIL

✅ Sheet ID automatically detect hota hai kyunki script Sheet ke andar se run hoti hai

4

Script Deploy Karo (Web App)

Script save karo (Ctrl+S) phir:

1. Top right mein "Deploy" button click karo

2. "New Deployment" select karo

3. "Web App" select karo

4. Yeh settings karo:

Execute as: → Me (apka Google account) Who has access: → Anyone

5. "Deploy" click karo → Permission maange to "Allow" karo

6. Web App URL copy karo — kuch aisa hoga:

https://script.google.com/macros/s/AKfycby.../exec

⚠️ Yeh URL zaroor save karo — Step 5 mein HTML files mein paste karna hai

5

URL HTML Files Mein Paste Karo

free-demo.html aur contact.html mein yeh line dhundo:

const APPS_SCRIPT_URL = 'YOUR_APPS_SCRIPT_URL_HERE';

Aur apna URL paste karo:

const APPS_SCRIPT_URL = 'https://script.google.com/macros/s/AKfycby.../exec';

Dono files mein yeh change karo. Done! ✅

6

Test Karo!

Ab free-demo.html kholo aur form fill karke submit karo. Phir:

📊 Google Sheets Mein Check Karo

Sheet mein "📅 Demo Bookings" tab mein nayi row aayegi apki information ke saath

📧 Gmail Check Karo

Apki email par notification aayega: "🎯 New Demo Booking — TRIGDA"

🎉 Sab kaam karta hai! Ab har form submission automatically save aur notify hoga!
